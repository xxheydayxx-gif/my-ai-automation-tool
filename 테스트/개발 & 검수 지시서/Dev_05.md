# Dev_05. 새 계약 준비 마법사, 동적 질문, 자동 저장

## 목표

사업부서 담당자가 계약 기본정보를 입력하면 계약 유형에 따라 후속 질문이 동적으로 나타나고, 사전점검으로 이어지는 준비 마법사를 구현한다.

## 구현 범위

- 새 계약 생성
- 기본정보 입력 폼
- 계약 유형별 질문 분기
- 동적 추가 질문
- 자동 저장
- 입력값 검증
- 유사 사업 불러오기

## 개발 지시

1. 기본 입력 필드는 명세서의 FLD-001부터 FLD-021을 우선 반영한다.
2. 계약 대상은 초기 실증 범위인 물품, 일반용역, 정보화용역을 우선 지원한다.
3. 정보화용역 선택 시 정보시스템 접근, 외부 시스템 연계, 보안 검토 질문을 노출한다.
4. 반복·갱신 선택 시 기존 계약 ID 입력 또는 유사 사업 검색을 노출한다.
5. 긴급성 또는 특정 업체 검토가 `예`이면 사유 입력을 필수로 한다.
6. 입력값은 변경 후 일정 시간 내 자동 저장하고 저장 시각을 표시한다.
7. 필수값 오류는 저장은 허용하되 제출과 사전점검 실행은 차단한다.
8. 사용자가 `모름`을 선택할 수 있는 항목은 담당자 검토 필요로 이어지게 한다.

## UI 개발 지시

- 마법사는 단계형 폼으로 구성한다.
- 현재 단계, 완료 단계, 오류 단계가 상단에 표시되어야 한다.
- 필수 입력 오류는 해당 필드 가까이에 표시한다.
- 자동 저장 상태는 상단 또는 하단 고정 영역에 표시한다.
- 긴 폼은 모바일에서 한 열로 전환한다.
- 금액, 날짜 범위, Boolean, 선택형 필드는 각 형식에 맞는 컨트롤을 사용한다.

## 완료 조건

- 계약 ID가 생성된다.
- 유형별 질문 분기가 동작한다.
- 자동 저장이 동작하고 저장 실패 시 재시도 안내가 보인다.
- 필수값 미입력 시 사전점검 실행이 차단된다.
- 사전점검 결과 화면으로 이동할 수 있다.
