# Dev_07. 사전점검 결과, 제출 서류, 서식 초안

## 목표

사전점검 결과 화면에서 계약 방식 후보, 필요 절차, 제출 서류, 위험 알림, 예상 일정, 서식 초안을 한 번에 확인하고 다음 업무로 넘길 수 있게 한다.

## 구현 범위

- 사전점검 결과 화면
- 제출 서류 체크리스트
- 첨부파일 업로드
- 누락 문서 탐지
- 구버전 서식 탐지
- 서식 초안 생성
- 예상 일정 생성
- 검토 요청 전송

## 개발 지시

1. 결과 화면은 계약 방식 후보, 절차, 서류, 위험, 규정, 일정, 서식, 검토 요청 영역으로 구성한다.
2. 제출 서류는 필수, 조건부, 해당 없음으로 구분한다.
3. 각 서류에는 산출 근거와 담당자를 표시한다.
4. 파일 업로드 시 확장자, 용량, 버전, 필수 여부를 검사한다.
5. 구버전 서식은 교체 권고 또는 제출 차단 상태로 표시한다.
6. 서식 초안은 공통 필드를 자동 매핑하고, 자동 작성률을 표시한다.
7. 서식 3~5종을 우선 지원한다.
8. 검토 요청 시 계약부서 검토함에 티켓을 생성한다.

## UI 개발 지시

- 결과 화면 상단에 핵심 요약과 위험 배지를 표시한다.
- 체크리스트는 필터와 접기/펼치기를 제공한다.
- 첨부파일은 드래그 앤 드롭과 파일 선택을 모두 지원한다.
- 서식 초안은 미리보기, 다운로드, 수정 필요 필드 표시를 제공한다.
- 검토 요청 버튼은 필수 오류가 없을 때만 활성화한다.

## 완료 조건

- 사전점검 결과가 한 화면에 정리된다.
- 필수 서류 누락이 탐지된다.
- 서식 초안이 생성된다.
- 검토 요청 티켓이 생성된다.
