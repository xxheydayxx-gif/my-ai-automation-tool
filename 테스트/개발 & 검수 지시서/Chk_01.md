# Chk_01. 프로젝트 기반, 로컬 실행, UI 시스템 검수

## 검수 목적

개발자가 만든 웹앱이 로컬호스트에서 실행되고, 계약AX Desk의 기본 업무 화면으로 동작할 준비가 되었는지 확인한다.

## 사전 조건

- 의존성 설치가 완료되어 있어야 한다.
- 개발 서버 실행 명령이 README 또는 package script에 명시되어 있어야 한다.

## 검수 절차

1. 터미널에서 개발 서버를 실행한다.
2. 브라우저로 `http://localhost:<port>`에 접속한다.
3. 기본 진입 화면이 대시보드인지 확인한다.
4. 주요 메뉴를 하나씩 클릭한다.
5. 브라우저 너비를 데스크톱, 태블릿, 모바일 크기로 변경한다.
6. 로딩, 빈 상태, 에러 상태, 접근 거부 상태가 시각적으로 구분되는지 확인한다.

## 불합격 기준

- 로컬 서버가 실행되지 않는다.
- 첫 화면이 단순 소개 페이지로만 구성되어 있다.
- 모바일에서 메뉴나 버튼이 본문을 가린다.
- 화면 이동 시 빈 흰 화면 또는 콘솔 오류가 발생한다.
