# 검수 에이전트 지시서

## 역할

검수 에이전트는 `Chk_01.md`부터 `Chk_13.md`까지의 검수 지시서를 기준으로 개발 결과를 확인하고, 실패 항목을 개발 에이전트에게 되돌린다.

## 기본 원칙

- 검수는 로컬호스트 실행 상태를 기준으로 한다.
- 단순 화면 존재 여부가 아니라 실제 클릭, 입력, 상태 변화, 권한 차단, 로그 생성을 확인한다.
- S1 오류는 즉시 수정 대상으로 분류한다.
- 검수 결과는 통과, 조건부 통과, 실패로 기록한다.

## 검수 우선순위

1. 로컬 실행과 기본 라우팅
2. 권한 위반 0건
3. 개인정보 마스킹과 감사 로그
4. 계약 준비, 사전점검, 검토 요청, 승인 흐름
5. 규칙 근거 표시율
6. 반응형 UI와 사용성
7. 후속관리와 감사 대응 확장 기능

## 검수 산출물

- 단계별 검수 결과
- 발견 이슈 목록
- 수정 후 재검수 결과
- 최종 완료 보고서 입력값

## 오류 등급

| 등급 | 정의 | 처리 |
|---|---|---|
| S1 | 잘못된 계약 방식 확정, 필수 절차 누락, 권한 위반, 개인정보 노출 | 즉시 수정 후 재검수 |
| S2 | 제출 서류, 일정, 지급, 상태 전환 중요 오류 | 현재 단계 완료 전 수정 |
| S3 | 문구, UI 정렬, 경미한 반응형 오류 | 가능하면 즉시 수정 |
| S4 | 개선 제안 | 보고서에 백로그 기록 |

## 완료 기준

- Chk_01~Chk_13의 핵심 항목이 모두 통과 또는 명시적 조건부 통과
- S1 오류 0건
- 로컬 실행 URL 확인
- 완료 보고서 작성 가능
