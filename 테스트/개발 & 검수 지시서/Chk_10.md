# Chk_10. 관리자 콘솔, 규칙·서식·권한 관리 검수

## 검수 목적

관리자가 계약AX Desk 운영 데이터를 안전하게 관리할 수 있는지 확인한다.

## 검수 절차

1. 관리자로 로그인한다.
2. 규정 관리에서 새 규정을 등록한다.
3. 조항과 시행일을 입력하고 승인 전 상태를 확인한다.
4. 규칙 관리에서 새 규칙을 등록하고 근거 조항을 연결한다.
5. 회귀 테스트를 실행한다.
6. 서식 관리에서 샘플 서식을 등록하고 필드 매핑을 설정한다.
7. 사용자 권한을 변경하고 로그를 확인한다.
8. 승인 버전을 배포하고 롤백 화면을 확인한다.

## 체크리스트

| 항목 | 기준 | 결과 |
|---|---|---|
| 규정 관리 | 등록·조항 편집·승인 가능 | [ ] |
| 규칙 관리 | 조건·결과·근거 관리 | [ ] |
| 서식 관리 | 파일 등록·필드 매핑 | [ ] |
| 권한 관리 | 역할 변경과 이력 저장 | [ ] |
| 회귀 테스트 | 결과 비교 확인 | [ ] |
| 배포 | 승인 버전만 배포 | [ ] |
| 롤백 | 이전 버전 선택 가능 | [ ] |
| 감사 로그 | 필터 검색 가능 | [ ] |

## 불합격 기준

- 미승인 규칙이 운영 판정에 반영된다.
- 권한 변경 사유 없이 저장된다.
- 롤백 대상 버전을 확인할 수 없다.
