# Dev_10. 관리자 콘솔, 규칙·서식·권한 관리

## 목표

관리자가 규정, 규칙, 서식, 사용자 권한, 회귀 테스트, 배포와 롤백을 운영할 수 있는 콘솔을 구현한다.

## 구현 범위

- 규정 관리
- 규칙 관리
- 서식 관리
- 사용자·권한 관리
- 회귀 테스트 실행
- 배포·롤백
- 감사 로그 조회
- 운영 품질 리포트

## 개발 지시

1. 규정은 원문, 조항, 시행일, 종료일, 등급, 승인 상태를 관리한다.
2. 규칙은 조건, 결과, 근거, 우선순위, 버전, 승인자를 관리한다.
3. 서식은 파일, 필드 매핑, 적용 시작일, 종료일, 폐기 여부를 관리한다.
4. 규정·규칙·서식은 승인 전 운영 반영되지 않게 한다.
5. 회귀 테스트는 과거 계약 사례를 입력으로 판정 결과 변화를 비교한다.
6. 배포는 승인 버전만 가능하며 롤백 대상 버전을 선택할 수 있게 한다.
7. 감사 로그는 사용자, 대상, 행동, 기간, 심각도 필터를 제공한다.

## UI 개발 지시

- 관리자 콘솔은 탭 또는 좌측 서브메뉴로 구성한다.
- 관리 테이블은 검색, 필터, 정렬, 페이지네이션을 제공한다.
- 규칙 편집 화면은 조건 빌더 형태로 구현한다.
- 서식 필드 매핑은 원본 필드와 시스템 필드를 나란히 매칭한다.
- 회귀 테스트 결과는 변경 없음, 변경 있음, 오류로 구분한다.

## 완료 조건

- 규정, 규칙, 서식을 등록·수정·승인할 수 있다.
- 권한 변경이 가능하고 이력이 남는다.
- 회귀 테스트 결과를 확인할 수 있다.
- 승인 버전 배포와 롤백 UI가 동작한다.
