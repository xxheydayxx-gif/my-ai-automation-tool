# Dev_12. 검사·검수, 대금 지급, 하자관리

## 목표

Phase 3~4 확장 기능으로 검사·검수, 지급 준비, 하자관리까지 계약 후속 업무를 연결한다.

## 구현 범위

- 검사·검수 요청
- 검사조서 초안
- 검사 결과 등록
- 지급 준비 상태
- 증빙 점검
- 지급 완료 처리
- 하자관리 대상 등록
- 보증서 만료 알림

## 개발 지시

1. 이행 완료 또는 기성검사 조건에서 검사 요청을 생성한다.
2. 검사조서는 계약 기본정보, 납품일, 검사자, 결과, 특이사항을 자동 입력한다.
3. 검사 완료 후 지급 준비 업무를 재무 담당자에게 생성한다.
4. 지급 준비 단계에서는 세금계산서, 검수조서, 계약서, 계좌 정보 등 증빙 체크를 수행한다.
5. 지급 완료 후 하자관리 대상이면 보증 기간과 보증서 만료일을 등록한다.
6. 보증서 만료 D-60, 하자 점검 D-30 알림을 생성한다.
7. 하자 발생 시 접수, 조치, 종료 상태를 기록한다.

## UI 개발 지시

- 검사 화면은 요청 목록, 검사 상세, 조서 미리보기로 구성한다.
- 지급 화면은 증빙 체크리스트와 지급 가능 상태를 명확히 보여준다.
- 하자관리 화면은 대상 계약, 보증 기간, 만료 위험, 조치 상태를 테이블로 표시한다.
- 재무와 사업부서의 화면 권한을 분리한다.

## 완료 조건

- 검사 요청과 검사 완료 상태가 동작한다.
- 검사조서 초안이 생성된다.
- 지급 준비 업무와 증빙 체크가 동작한다.
- 하자관리 대상과 만료 알림이 생성된다.
