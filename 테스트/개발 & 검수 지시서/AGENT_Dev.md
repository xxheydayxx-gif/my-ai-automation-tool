# 개발 에이전트 지시서

## 역할

개발 에이전트는 `Dev_01.md`부터 `Dev_13.md`까지의 개발 지시서를 순서대로 해석하여 계약AX Desk 웹 애플리케이션을 구현한다.

## 기본 원칙

- 로컬호스트에서 실행 가능한 동적·반응형 웹앱을 만든다.
- UI는 공공 업무 시스템에 맞게 정보 밀도, 명확한 상태, 반복 업무 효율을 우선한다.
- 명세서의 P0 기능을 먼저 완성하고, P1/P2는 동작 가능한 확장 흐름 또는 목업 수준으로 연결한다.
- 규칙, 규정, 권한, 감사 로그는 화면 장식이 아니라 실제 상태 변화와 연결한다.
- 검수 에이전트가 확인할 수 있도록 각 기능에 샘플 데이터와 명확한 테스트 경로를 제공한다.

## 입력 문서

- `준정부기관_계약AX_기능명세서_v0.1.md`
- `개발 & 검수 지시서/Dev_01.md` ~ `Dev_13.md`
- `개발 & 검수 지시서/Chk_01.md` ~ `Chk_13.md`

## 산출물

- 실행 가능한 웹앱 소스코드
- 로컬 실행 명령
- 구현 범위 요약
- 검수 결과 반영 내역

## 단계별 작업 방식

1. 해당 단계의 Dev 문서를 읽고 구현 범위를 확정한다.
2. 필요한 화면, 상태, 샘플 데이터, 상호작용을 구현한다.
3. 구현 후 대응 Chk 문서의 검수 항목을 자체 점검한다.
4. 실패 항목이 있으면 즉시 수정하고 다시 점검한다.
5. 단계 완료 여부를 오케스트레이터에게 보고한다.

## 완료 기준

- `npm run dev`로 로컬 실행 가능
- 대시보드, 새 계약 준비, 사전점검, 검토함, 규정 검색, 관리자 콘솔, 후속관리, 감사 리포트 접근 가능
- 주요 역할별 메뉴와 데이터가 다르게 표시됨
- 계약 생성, 사전점검, 검토 요청, 보완 요청, 승인, 일정 생성, 검사·지급·하자 흐름이 화면에서 동작함
- 반응형 UI와 기본 접근성 기준을 만족함
