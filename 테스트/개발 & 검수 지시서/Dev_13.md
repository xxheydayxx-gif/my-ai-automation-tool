# Dev_13. 감사 대응, 분석 리포트, 운영 안정화

## 목표

감사 대응 자료를 계약별로 패키징하고, 운영 KPI와 품질 리포트를 제공하며, 제한 운영 전 최종 안정화 기준을 충족한다.

## 구현 범위

- 감사 패키지 생성
- 계약별 판단 근거 묶음
- 상태 변경·승인·다운로드 로그
- 유사 계약 검색
- 반복 오류 분석
- KPI 리포트
- 성능·보안·접근성 점검
- 배포 전 점검표

## 개발 지시

1. 감사 패키지는 계약 기본정보, 입력값, 판정 결과, 근거 조항, 제출 서류, 검토 의견, 승인 이력, 상태 변경 로그를 포함한다.
2. 패키지는 PDF 또는 ZIP 등 기관 정책에 맞는 형식으로 내려받을 수 있게 한다.
3. 분석 리포트는 준비시간, 반려율, 서류 누락률, 판정 수용률, 사용자 활성화를 표시한다.
4. 반복 오류 분석은 보완 요청 사유와 문서 누락 유형을 집계한다.
5. 제한 운영 KPI는 실제 사용자 20~50명, 실제 계약 30건 이상, S1 오류 0건 기준으로 표시한다.
6. 배포 전 성능, 권한, 개인정보, 접근성, 백업 복구 점검 결과를 기록한다.

## UI 개발 지시

- 감사 대응 화면은 계약 검색, 패키지 구성 미리보기, 다운로드 이력으로 구성한다.
- 분석 리포트는 기간, 부서, 계약 유형 필터를 제공한다.
- KPI는 숫자와 추세를 함께 보여주되 과도한 장식은 피한다.
- 운영 점검표는 체크리스트와 담당자 서명 상태를 제공한다.

## 완료 조건

- 계약별 감사 패키지를 생성할 수 있다.
- 분석 리포트가 권한 범위 내 데이터를 집계한다.
- 배포 전 점검표를 기록할 수 있다.
- S1 오류, 권한 위반, 개인정보 마스킹 누락을 별도로 추적한다.
