# 계약AX Desk 개발 & 검수 지시서 목차

본 폴더는 `준정부기관_계약AX_기능명세서_v0.1.md`를 기준으로 로컬호스트에서 실행 가능한 동적·반응형 웹 사이트 개발 단계를 나눈 작업 지시서와 검수 지시서이다.

## 기본 개발 전제

- 목표 산출물: `localhost`로 접속 가능한 웹 애플리케이션
- 화면 성격: 단순 안내 페이지가 아니라 실제 업무 입력, 판정, 검토, 관리가 가능한 동적 업무 시스템
- 우선 구현 범위: 내부 실증용 Phase 1 P0 기능
- 확장 구현 범위: 체결, 이행, 검사·검수, 지급, 하자관리, 감사 대응
- UI 필수 조건: 데스크톱·태블릿·모바일 반응형, 공공 업무 시스템에 맞는 조용하고 밀도 있는 화면, 모든 주요 기능은 실제 조작 가능한 상태로 구현
- 보안 원칙: 역할 기반 권한, 문서 권한 상속, 개인정보 마스킹, 감사 로그
- AI 원칙: 규칙 엔진과 생성형 AI 역할 분리, 근거 없는 답변 제한, 담당자 검토 전환
