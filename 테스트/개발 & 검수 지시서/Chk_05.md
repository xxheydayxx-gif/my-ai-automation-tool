# Chk_05. 새 계약 준비 마법사 검수

## 검수 목적

계약 준비 화면이 실제 업무 입력 흐름을 지원하고, 동적 질문과 자동 저장이 정상 동작하는지 확인한다.

## 검수 절차

1. 대시보드에서 `새 계약 준비`를 시작한다.
2. 물품 계약을 선택하고 필수값을 입력한다.
3. 자동 저장 시각이 갱신되는지 확인한다.
4. 정보화용역으로 변경한다.
5. 정보시스템 접근, 외부 연계, 보안 검토 질문이 나타나는지 확인한다.
6. 긴급성을 `예`로 선택하고 사유를 비워 둔다.
7. 사전점검 실행이 차단되는지 확인한다.
8. 사유를 입력한 뒤 사전점검을 실행한다.

## 체크리스트

| 항목 | 기준 | 결과 |
|---|---|---|
| 계약 생성 | 신규 계약 ID 생성 | [ ] |
| 기본 필드 | FLD-001~021 주요 필드 반영 | [ ] |
| 유형 분기 | 물품·일반용역·정보화용역 질문 차이 | [ ] |
| 조건부 필드 | 반복·긴급·특정 업체 사유 필수 | [ ] |
| 자동 저장 | 저장 시각 표시 | [ ] |
| 입력 검증 | 오류 위치 표시 | [ ] |
| 모바일 폼 | 한 열 구성, 입력 가능 | [ ] |

## 불합격 기준

- 계약 유형 변경 시 질문이 갱신되지 않는다.
- 필수 사유 없이 사전점검이 실행된다.
- 자동 저장 실패가 조용히 무시된다.
