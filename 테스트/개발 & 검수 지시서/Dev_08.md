# Dev_08. 규정 검색, 근거 기반 AI 답변 UI

## 목표

사용자가 계약 규정을 질문하면 권한 범위 내 규정과 문서만 검색하고, 답변에는 반드시 근거 조항과 시행일을 표시한다.

## 구현 범위

- 규정 검색 화면
- 계약 유형·단계 필터
- AI 답변 영역
- 근거 조항 목록
- 원문 링크 또는 조항 상세
- 담당자 문의 전환
- 답변 피드백
- 개인정보·민감정보 필터

## 개발 지시

1. 검색 입력은 일반 키워드와 자연어 질문을 모두 지원한다.
2. 검색 대상은 사용자 권한 필터를 통과한 규정·문서만 포함한다.
3. 답변에 근거가 없으면 답변 대신 `근거 확인 필요` 상태를 표시한다.
4. 답변에는 규정명, 조·항·호, 시행일, 출처, 신뢰 수준을 표시한다.
5. 개인정보와 민감정보는 모델 호출 전 마스킹한다.
6. 사용자는 답변에 대해 도움됨, 수정 필요, 담당자 문의를 선택할 수 있다.
7. 모든 질문, 검색 결과, 피드백은 감사 로그 또는 AI 로그로 저장한다.

## UI 개발 지시

- 화면은 검색 입력, 필터, 답변, 근거 목록, 피드백 영역으로 구성한다.
- 근거 조항은 답변 옆에 고정 또는 접이식 패널로 표시한다.
- 필터는 계약 유형, 계약 단계, 규정 종류, 시행일 기준을 제공한다.
- 답변의 확정성을 과도하게 표현하지 않는다.
- 모바일에서는 답변 아래에 근거 목록이 이어지도록 구성한다.

## 완료 조건

- 권한 범위 내 검색만 수행된다.
- 근거 없는 답변이 차단된다.
- 개인정보 마스킹이 적용된다.
- 피드백과 문의 전환이 동작한다.
