# Chk_06. 규칙 엔진, 규정 레지스트리, 계약 방식 판정 검수

## 검수 목적

계약 방식 판정이 규칙과 근거 조항을 기반으로 동작하고, 불확실한 경우 담당자 검토로 전환되는지 확인한다.

## 검수 절차

1. 물품 계약 샘플을 생성한다.
2. 추정가격과 계약 조건을 입력한다.
3. 사전점검을 실행한다.
4. 계약 방식 후보와 근거 조항이 표시되는지 확인한다.
5. 필수 판단 조건을 `모름`으로 변경한다.
6. 담당자 검토 필요 상태가 생성되는지 확인한다.
7. 입력값을 변경하고 판정 비교 이력을 확인한다.
8. 관리자 또는 개발자 테스트에서 규칙 단위 테스트를 실행한다.

## 체크리스트

| 항목 | 기준 | 결과 |
|---|---|---|
| 규정 데이터 | 규정명, 조항, 시행일 존재 | [ ] |
| 규칙 실행 | 조건별 후보 산출 | [ ] |
| 근거 표시 | 모든 후보에 근거 표시 | [ ] |
| 불확실 처리 | 담당자 검토 필요 전환 | [ ] |
| 보완 질문 | 미충족 입력 질문 생성 | [ ] |
| 판정 이력 | 변경 전후 비교 저장 | [ ] |
| 테스트 | 규칙 단위 테스트 실행 가능 | [ ] |

## 불합격 기준

- 근거 조항 없이 계약 방식이 표시된다.
- 확정할 수 없는 상황인데 확정처럼 표시된다.
- 규칙 값이 코드에만 고정되어 있다.
