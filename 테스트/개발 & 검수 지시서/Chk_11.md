# Chk_11. 체결 체크, 이행 일정, 변경·지체 검토 검수

## 검수 목적

계약 체결 이후 후속 업무가 자동 생성되고, 변경·지체 위험을 관리할 수 있는지 확인한다.

## 검수 절차

1. 검토 완료 계약을 체결 준비 상태로 이동한다.
2. 체결 체크리스트 필수 항목을 확인한다.
3. 체결 완료 처리한다.
4. 착수, 납품, 검사, 지급 일정이 자동 생성되는지 확인한다.
5. 이행 일정 화면에서 캘린더와 목록을 전환한다.
6. 계약 기간 또는 금액 변경을 입력한다.
7. 변경 전후 비교표를 확인한다.
8. 납품 지연 값을 입력해 지체 검토 티켓을 생성한다.

## 불합격 기준

- 체결 완료 후 후속 일정이 생성되지 않는다.
- 변경 전후 값이 이력으로 남지 않는다.
- 지체 위험이 검토 업무로 연결되지 않는다.
