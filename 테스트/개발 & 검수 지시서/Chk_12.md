# Chk_12. 검사·검수, 대금 지급, 하자관리 검수

## 검수 목적

검사 완료 후 지급과 하자관리로 이어지는 후속 업무 흐름이 정상 동작하는지 확인한다.

## 검수 절차

1. 이행 중 계약에서 검사 요청을 생성한다.
2. 검사 담당자로 검사 상세를 열어 검사조서 초안을 확인한다.
3. 검사 결과를 완료로 등록한다.
4. 재무 담당자로 지급 준비 업무가 생성되는지 확인한다.
5. 증빙 체크리스트를 확인하고 누락 항목을 남긴다.
6. 증빙을 모두 완료하고 지급 완료 처리한다.
7. 하자관리 대상 계약으로 설정한다.
8. 보증 기간과 만료 알림이 생성되는지 확인한다.

## 체크리스트

| 항목 | 기준 | 결과 |
|---|---|---|
| 검사 요청 | 이행 계약에서 생성 가능 | [ ] |
| 검사조서 | 기본정보 자동 입력 | [ ] |
| 검사 완료 | 상태가 지급 준비로 연결 | [ ] |
| 지급 업무 | 재무 담당자 업무 생성 | [ ] |
| 증빙 점검 | 누락 항목 표시 | [ ] |
| 지급 완료 | 지급 이력 저장 | [ ] |
| 하자관리 | 보증 기간·만료 알림 생성 | [ ] |

## 불합격 기준

- 검사 완료 후 지급 업무가 생성되지 않는다.
- 증빙 누락 상태에서 지급 가능으로 표시된다.
- 하자 대상인데 만료 알림이 생성되지 않는다.
