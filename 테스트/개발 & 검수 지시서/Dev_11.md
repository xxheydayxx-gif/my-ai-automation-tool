# Dev_11. 체결 체크, 이행 일정, 변경·지체 검토

## 목표

Phase 2 확장 기능으로 계약 체결 이후의 착수, 납품, 검사 준비, 변경계약, 지체 위험을 자동 업무로 연결한다.

## 구현 범위

- 계약 체결 체크리스트
- 체결 완료 처리
- 착수·납품·검사 일정 자동 생성
- 이행 일정 캘린더
- 지연 위험 알림
- 변경계약 비교
- 지체 검토 티켓

## 개발 지시

1. 계약 체결 준비 상태에서 필수 체결 체크리스트를 표시한다.
2. 체결 완료 시 계약 기간과 납품 목표일 기준으로 일정과 알림을 자동 생성한다.
3. 착수일 D-3, 납품일 D-14, 지급 예정일 D-5 등 이벤트 기준 알림을 등록한다.
4. 과업, 금액, 기간 변경 입력 시 변경 전후 비교표를 생성한다.
5. 납품 지연 가능성이 있으면 지체 검토 티켓을 생성한다.
6. 변경계약 검토와 지체 검토는 계약부서 검토함과 연결한다.

## UI 개발 지시

- 이행 일정은 캘린더 보기와 목록 보기를 모두 제공한다.
- 일정에는 유형, 기한, 담당자, 상태, 위험 배지를 표시한다.
- 변경계약 비교는 변경 전후 값을 나란히 보여준다.
- 지체 위험은 계약 상세와 대시보드에 모두 표시한다.

## 완료 조건

- 체결 완료 후 일정이 자동 생성된다.
- 일정 알림이 대시보드와 알림 센터에 표시된다.
- 변경 전후 비교가 가능하다.
- 지체 검토 티켓이 생성된다.
