# Dev_04. 대시보드, 업무함, 알림 센터

## 목표

사용자가 처리해야 할 계약 업무, 지연 위험, 상태별 현황, 최근 규정 변경을 한 화면에서 확인하게 한다.

## 구현 범위

- 대시보드 화면
- 내 업무함
- 계약 상태별 집계
- 지연 위험 표시
- 빠른 시작 버튼
- 최근 규정 변경 위젯
- 인앱 알림 센터

## 개발 지시

1. 사용자 권한 범위 내 계약만 집계한다.
2. 업무함에는 단계, 기한, 계약명, 담당자, 우선순위를 표시한다.
3. 지연 위험은 현재일과 목표일을 기준으로 정상, 주의, 위험으로 표시한다.
4. 빠른 시작은 물품, 일반용역, 정보화용역 신규 계약 준비로 연결한다.
5. 최근 규정 변경은 영향받는 규칙과 서식을 연결할 수 있게 한다.
6. 알림은 읽음/안읽음, 유형, 대상 계약 링크를 가진다.
7. 관리자 역할은 KPI 카드를 추가로 볼 수 있다.

## UI 개발 지시

- 대시보드는 한눈에 스캔 가능한 밀도 있는 레이아웃으로 구성한다.
- 상태별 집계는 숫자 카드와 미니 차트를 함께 사용한다.
- 업무 목록은 테이블과 모바일 카드형 목록을 반응형으로 전환한다.
- 빠른 시작은 명확한 아이콘과 텍스트 버튼으로 제공한다.
- 알림 센터는 헤더 아이콘에서 열 수 있는 패널로 구현한다.

## 완료 조건

- 역할별 대시보드 내용이 다르게 표시된다.
- 업무 클릭 시 해당 계약 또는 검토 화면으로 이동한다.
- 알림 읽음 처리가 동작한다.
- 모바일에서 주요 업무 확인과 빠른 시작이 가능하다.
