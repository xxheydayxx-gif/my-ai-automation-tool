# Chk_08. 규정 검색, 근거 기반 AI 답변 UI 검수

## 검수 목적

규정 검색이 근거 기반으로 동작하며, 권한과 개인정보 보호 원칙을 지키는지 확인한다.

## 검수 절차

1. 사업부서 사용자로 규정 검색 화면에 접속한다.
2. 계약 방식 관련 질문을 입력한다.
3. 답변과 근거 조항이 함께 표시되는지 확인한다.
4. 계약 유형 필터를 변경한다.
5. 검색 결과가 필터에 맞게 달라지는지 확인한다.
6. 권한 없는 내부 문서명을 검색한다.
7. 결과에 노출되지 않는지 확인한다.
8. 개인정보가 포함된 질문을 입력하고 마스킹 로그를 확인한다.
9. 답변 피드백을 남긴다.

## 체크리스트

| 항목 | 기준 | 결과 |
|---|---|---|
| 자연어 검색 | 질문 입력 가능 | [ ] |
| 필터 | 유형·단계·규정 종류 필터 | [ ] |
| 근거 표시 | 답변마다 조항·시행일 표시 | [ ] |
| 무근거 차단 | 근거 없을 때 답변 제한 | [ ] |
| 권한 필터 | 권한 없는 문서 미노출 | [ ] |
| 개인정보 | 모델 호출 전 마스킹 | [ ] |
| 피드백 | 도움됨·수정 필요 저장 | [ ] |

## 불합격 기준

- 근거 없이 단정적인 답변을 표시한다.
- 권한 없는 원문이나 첨부가 검색된다.
- 개인정보가 그대로 AI 로그 또는 요청에 남는다.
