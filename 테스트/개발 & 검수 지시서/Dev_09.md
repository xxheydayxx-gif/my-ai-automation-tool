# Dev_09. 계약부서 검토함, 문서 오류 점검, 보완 요청

## 목표

계약 담당자가 사전점검 결과와 제출 문서를 검토하고, 보완 요청 또는 승인 처리를 할 수 있는 검토함을 구현한다.

## 구현 범위

- 계약부서 검토 큐
- 필터와 정렬
- 계약 입력값 요약
- 규칙 실행 결과 확인
- 원문 규정 확인
- 문서 오류 점검
- 보완 요청
- 승인과 예외 처리
- 검토 의견 타임라인

## 개발 지시

1. 검토함은 배정 계약, 신규 요청, 보완 회신, 지연 위험을 구분한다.
2. 계약 담당자는 입력값, 판정 결과, 제출 서류, 첨부파일, 근거 조항을 한 화면에서 확인할 수 있어야 한다.
3. 문서 오류 점검은 금액, 날짜, 첨부 누락, 서식 버전을 우선 검사한다.
4. 보완 요청은 항목별로 작성하고 담당자에게 알림을 생성한다.
5. 승인 시 계약 방식 확정값, 승인자, 승인일, 의견을 저장한다.
6. 예외 처리는 사유 입력과 법무·감사 검토 전환을 지원한다.
7. 모든 검토 행동은 감사 로그에 기록한다.

## UI 개발 지시

- 검토함은 테이블 중심으로 구성하고 상태, 기한, 위험, 담당자 필터를 제공한다.
- 검토 상세는 좌측 계약 요약, 우측 검토 액션 또는 탭 구조로 구성한다.
- 보완 요청 모달은 항목 선택, 상세 사유, 첨부 요청 여부를 포함한다.
- 승인 버튼은 확인 모달을 거치며 근거 요약을 보여준다.
- 모바일에서는 검토 큐 조회와 주요 상태 확인을 우선 지원한다.

## 완료 조건

- 검토 요청 티켓이 검토함에 표시된다.
- 문서 오류 점검 결과가 표시된다.
- 보완 요청과 승인 처리가 상태를 변경한다.
- 검토 이력과 감사 로그가 남는다.
