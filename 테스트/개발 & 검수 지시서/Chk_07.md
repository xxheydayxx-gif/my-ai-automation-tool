# Chk_07. 사전점검 결과, 제출 서류, 서식 초안 검수

## 검수 목적

사전점검 결과가 업무 담당자가 다음 행동을 결정할 수 있을 만큼 명확하며, 서류와 서식 기능이 동작하는지 확인한다.

## 검수 절차

1. 사전점검을 완료한 계약의 결과 화면에 접속한다.
2. 계약 방식 후보, 절차, 위험, 일정이 표시되는지 확인한다.
3. 제출 서류 체크리스트에서 필수 서류를 확인한다.
4. 필수 첨부 없이 검토 요청을 시도한다.
5. 제출 차단 또는 경고가 표시되는지 확인한다.
6. 샘플 파일을 업로드한다.
7. 서식 초안을 생성하고 미리보기를 확인한다.
8. 검토 요청을 전송하고 검토함에 티켓이 생기는지 확인한다.

| 결과 요약 | 후보·절차·위험·일정 표시 | [ ] |
| 서류 분류 | 필수·조건부·해당 없음 구분 | [ ] |

## 불합격 기준

- 필수 서류 누락 상태에서도 아무 경고 없이 요청된다.
- 서식 자동작성 필드가 사용자 입력과 다르다.
- 결과 화면에 근거가 없어 검토자가 판단할 수 없다.
