## 6. 실행 및 검증 기록

```text
node --check server.js
node --check public/app.js
npm.cmd run test
Invoke-WebRequest http://localhost:4173
Invoke-WebRequest http://localhost:4173/styles.css
Invoke-WebRequest http://localhost:4173/app.js
```

검증 결과:

- `server.js` 문법 검사 통과
- `public/app.js` 문법 검사 통과
- `npm.cmd run test` 통과
- `http://localhost:4173` 200 응답
- CSS, JS 정적 파일 200 응답

## 7. 잔여 리스크와 후속 과제

| 등급 | 항목 | 설명 |
|---|---|---|
| S1 | 없음 | 현재 정적 검수 기준 권한 위반·개인정보 직접 노출·실행 불가 이슈 없음 |
| S2 | 실제 DB 미연계 | 현재 데이터는 브라우저 메모리 기반 목업이므로 새로고침 시 상태가 초기화됨 |
| S2 | 실제 AI/RAG 미연계 | 규정 검색은 근거 기반 UI와 목업 응답이며 실제 검색 인덱스·모델 호출은 미구현 |
| S2 | 실제 파일 생성 미구현 | 서식 초안, 감사 패키지는 UI와 로그 중심이며 DOCX/PDF/ZIP 생성은 후속 개발 필요 |
| S3 | 자동 브라우저 시각 검수 제한 | 현재 in-app browser `iab`와 Playwright 패키지를 사용할 수 없어 DOM 시각 검수는 수행하지 못함 |
| S3 | npm PowerShell 실행 정책 | PowerShell에서 `npm` 직접 실행이 차단되어 `npm.cmd` 또는 `node server.js` 사용 필요 |
