# Chk_09. 계약부서 검토함, 문서 오류 점검, 보완 요청 검수

## 검수 목적

계약 담당자가 제출된 계약을 검토하고 보완 또는 승인할 수 있는지 확인한다.

## 검수 절차

1. 사업부서 사용자로 검토 요청을 생성한다.
2. 계약 담당자로 전환해 검토함에 접속한다.
3. 요청 계약이 목록에 표시되는지 확인한다.
4. 검토 상세에서 입력값, 규칙 결과, 첨부, 근거를 확인한다.
5. 필수 첨부를 제거하거나 구버전 서식 샘플을 넣어 오류 점검을 실행한다.
6. 보완 요청을 작성한다.
7. 사업부서 사용자에게 알림과 보완 상태가 표시되는지 확인한다.
8. 보완 후 계약 담당자로 승인 처리한다.

## 불합격 기준

- 검토 요청이 검토함에 나타나지 않는다.
- 보완 요청 후 상태와 알림이 바뀌지 않는다.
- 승인 이력에 승인자와 근거가 남지 않는다.
