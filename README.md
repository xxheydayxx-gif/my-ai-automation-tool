# AX Study Notes

AI Transformation(AX)을 공부하며 배운 내용을 정리하는 개인 학습용 저장소입니다.

생성형 AI, 업무 자동화, 데이터 활용, 프롬프트 작성, AI 도구 적용 사례 등을 직접 실습하고 기록합니다.
단순히 개념만 모으기보다, 실제 업무에 적용할 수 있는 작은 예제를 꾸준히 쌓는 것을 목표로 합니다.

## 학습 목표

* AI Transformation의 기본 개념 이해
* 생성형 AI와 주요 AI 도구 활용법 익히기
* 반복 업무를 자동화하는 방법 학습
* 프롬프트 작성 및 개선 과정 기록
* 실제 업무에 적용할 수 있는 AX 아이디어 정리
* 작은 실습 프로젝트를 통해 실행 경험 축적

## 주요 내용

### 1. AX 기본 개념

* AX란 무엇인가
* 디지털 전환(DX)과 AX의 차이
* AI를 활용한 업무 방식의 변화
* 조직과 개인이 준비해야 할 역량

### 2. 생성형 AI 활용

* ChatGPT 등 생성형 AI 도구 사용법
* 질문을 구체화하는 방법
* 업무별 프롬프트 작성 예시
* 답변 검토 및 개선 방법
* AI 활용 시 주의할 점

### 3. 업무 자동화

* 반복 업무 찾기
* 문서 작성 자동화
* 데이터 정리 자동화
* 일정 및 업무 관리 자동화
* 간단한 워크플로 설계

### 4. 데이터 활용

* 데이터 기초 개념
* 스프레드시트 활용
* 데이터 요약 및 분석
* 시각화 기초
* AI를 활용한 인사이트 도출

### 5. 실습 프로젝트

* 회의록 요약 자동화
* 이메일 초안 작성
* 업무 보고서 템플릿 제작
* 자료 조사 및 핵심 내용 정리
* 개인 학습 관리 도구 만들기


관심 있는 폴더를 열어 학습 기록과 실습 예제를 확인합니다.

## 학습 로드맵

### 1단계: AX 개념 익히기

* AX와 DX의 차이 이해
* 생성형 AI의 특징 파악
* AI 활용 사례 조사

### 2단계: AI 도구 사용하기

* 질문 작성 연습
* 문서 요약
* 아이디어 정리
* 이메일 및 보고서 초안 작성

### 3단계: 업무 자동화 실습

* 반복 업무 목록 작성
* 자동화 가능한 업무 선정
* 작은 자동화 프로젝트 제작

### 4단계: 나만의 활용 방식 만들기

* 자주 사용하는 프롬프트 정리
* 업무별 템플릿 제작
* 실습 결과 개선
* 실제 업무 적용 가능성 검토

## 진행 원칙

* 처음부터 완벽하게 만들지 않습니다.

* 실제로 도움이 되는 활용법을 중심으로 정리합니다.
* 배운 내용을 다시 사용할 수 있도록 예시를 남깁니다.
